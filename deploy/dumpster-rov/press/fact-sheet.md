## Key features
1. One thread for everything
2. Smart cards (links, places, photos, voice notes, to-dos)
3. Auto Piles
4. Dig in plain language
5. The send: every message drops into the dumpster and is filed
6. Share from anywhere

## Brand
Near-black and bone, with one color: Sent blue #2B5CFF, used only on messages the user sends.
Neutrals: Void #070707, Ink #0E0E0F, Graphite #17181A, Smoke #24262A, Ash #8B8F94, Bone #EEEEEC, Paper #F4F1EC.
